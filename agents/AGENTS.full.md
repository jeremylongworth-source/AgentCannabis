# AgentCannabis full routing

Use local AgentCannabis skills as the primary routing layer for Canadian cannabis compliance, quality, records, operations-governance, and evidence-review work.

For broad role-based requests, start with the narrowest professional wrapper below. For narrow single-workflow requests, choose the specific atomic skill from `skills/` when installed.

- Use `$cannabis-compliance-specialist` for cannabis compliance specialist support involving licence, role, product, inventory, reporting, complaints, safety, and audit evidence.
- Use `$cannabis-operations-manager` for cannabis operations manager support involving end-to-end operational governance, compliance evidence, quality systems, inventory, post-market, and safety escalation.
- Use `$cannabis-processing-technician` for cannabis processing technician support involving processing records, material intake, batch records, control measures, and deviation evidence.
- Use `$cannabis-production-manager` for cannabis production manager support involving cross-stage production evidence, resource and deviation review, hazard escalation, records, and inventory impacts.
- Use `$cannabis-quality-systems-specialist` for cannabis quality systems specialist support involving quality-system records, document control, training, CAPA, product quality, and post-market evidence.
- Use `$controlled-environment-cultivation-specialist` for controlled-environment cultivation specialist support involving environmental monitoring evidence, trend review, sensor coverage, and qualified escalation.
- Use `$ctls-inventory-specialist` for CTLS and inventory specialist support involving inventory reconciliation, CTLS readiness, loss/theft packages, destruction records, and discrepancy review.
- Use `$cultivation-manager-support` for cultivation manager support involving cultivation governance, capacity, deviations, people/role evidence, and safety escalation.
- Use `$cultivation-technician` for cultivation technician support involving daily cultivation record review, monitoring gaps, crop observations, and escalation packages.
- Use `$drying-curing-specialist` for drying and curing specialist support involving drying, curing, moisture, water activity, storage, and microbial-risk evidence review.
- Use `$master-grower-support` for master grower support involving crop-cycle evidence, plant health, environment records, and production variance review without optimization instructions.
- Use `$plant-health-specialist` for plant-health specialist support involving plant-health evidence, pest/disease observations, treatment records, and quality trend handoff.
- Use `$post-harvest-manager` for post-harvest manager support involving post-harvest workflow control, holds, quality packages, inventory, deviations, and complaints.
- Use `$post-harvest-technician` for post-harvest technician support involving harvest identity, intake, handling, drying, curing, and quality-record gaps.
- Use `$preventive-controls-specialist` for preventive controls specialist support involving hazard analysis, process controls, corrective actions, SOP execution, and safety escalation.
- Use `$processing-manager-support` for processing manager support involving processing authority, flow, yield reconciliation, hazard routing, GPP controls, and inventory review.
- Use `$qap-support` for QAP support involving QAP responsibility evidence, quality systems, product records, complaints, recalls, holds, and adverse-reaction packages.
- Use `$quality-control-specialist` for quality control specialist support involving sampling, COA review, OOS evidence, specifications, product quality records, and release package support.

Do not use AgentCannabis to approve regulated actions, provide cannabis production optimization, hazardous extraction instructions, pressure tuning, pesticide recommendations, CTLS manipulation, false release, concealed testing, professional sign-off, or autonomous legal, engineering, QAP, recall, lot-release, tax, or filing decisions.

Read the selected skill's `SKILL.md` before acting, then load referenced files only when needed. Preserve source-currentness limits, missing evidence, conflicting records, and human-approval boundaries in the output.
