# AgentCannabis skillset: cannabis-operations-manager

Use local AgentCannabis skills as the primary routing layer for cannabis operations manager support involving end-to-end operational governance, compliance evidence, quality systems, inventory, post-market, and safety escalation.

Use `$cannabis-operations-manager` when the request spans multiple member workflows, asks for role-level coordination, or needs a review brief that separates facts, assumptions, gaps, source-currentness limits, member workflow findings, and responsible human next steps.

For a narrow task, use the most specific installed atomic skill from `$cannabis-operations-manager`'s bundled `references/member-index.json`. If the atomic member skill is not installed, use `$cannabis-operations-manager` as the wrapper and cite the selected member workflow by name from the member index.
