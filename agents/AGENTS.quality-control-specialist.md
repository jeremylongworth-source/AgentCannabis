# AgentCannabis skillset: quality-control-specialist

Use local AgentCannabis skills as the primary routing layer for quality control specialist support involving sampling, COA review, OOS evidence, specifications, product quality records, and release package support.

Use `$quality-control-specialist` when the request spans multiple member workflows, asks for role-level coordination, or needs a review brief that separates facts, assumptions, gaps, source-currentness limits, member workflow findings, and responsible human next steps.

For a narrow task, use the most specific installed atomic skill from `$quality-control-specialist`'s bundled `references/member-index.json`. If the atomic member skill is not installed, use `$quality-control-specialist` as the wrapper and cite the selected member workflow by name from the member index.
