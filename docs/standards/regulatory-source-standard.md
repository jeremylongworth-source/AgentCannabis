# Regulatory source standard

Each source record declares `source_title`, `organization`, `jurisdiction`, `authority_level`, `source_url`, `publication_date`, `effective_date`, `last_verified`, `applicability`, `supersession_risk` and `used_by`. Also retain a stable ID, supported claims/provisions, freshness interval, verification method and any consolidation limit. Unknown publication/effective dates are null, never inferred from access dates.

Authority order: Cannabis Act/Regulations; Health Canada; CRA for its own excise system; other federal regulators; relevant provincial statutes/regulators; recognized standards; peer-reviewed science; high-quality technical literature; secondary discovery sources. Authority is topic-specific: CRA is primary for excise; provincial legislation controls provincial duties. The ordering does not make Health Canada authoritative about a provincial building approval.

Capture verified claims narrowly. A portal landing page establishes where to research; it does not establish every requirement below it. Do not mark an entire skill family legally verified because one general page was fetched.

Pest-control review requires current Canadian registration and label applicability, including crop/use/site and restrictions. No static approved-product list is distributed. Unknown applicability stops a treatment recommendation; a records review can still identify missing evidence.
