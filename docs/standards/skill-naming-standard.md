# Skill naming standard

Atomic names match the supplied taxonomy exactly. Use lowercase letters/digits separated by single hyphens, at most 64 characters, with no leading/trailing hyphen. Folder and frontmatter name must agree. Names describe one bounded deliverable.

Historical `Added` blocks repeating names in Families 14–17 are audit annotations, not extra skills. Family 13's added block supplies eight real additions to its fifteen original entries. Family 18's removed `audit-production-batch-record` must not enter the index. Validate 18 family totals and 233 globally unique atomic names.

The diagram-only `identify-responsible-role` resolves to the two declared role skills. Record aliases explicitly; never silently create new atomic entries to fix a diagram.

Skillset names are the 18 professional names declared by the roadmap. They are compositions, not regulated credentials. Changes to canonical names/count require an explicit taxonomy revision with migration notes and revised acceptance evidence.
