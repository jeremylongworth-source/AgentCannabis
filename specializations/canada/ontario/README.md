# Ontario cannabis overlay

Status: research overlay, not a site-specific compliance determination.

## Scope

This overlay records Ontario-specific evidence routes for AgentCannabis skills. It is used for workplace-safety, fire-code, facility, and authority-having-jurisdiction questions that cannot be resolved from federal cannabis sources alone.

## Current evidence

The source registry includes:

- `ON-OHSA-DUTIES`: official Ontario workplace-duty guidance excerpt.
- `ON-FIRE-2019-AMENDMENT`: historical e-Laws amendment evidence for cannabis hazardous-extraction treatment.

The current consolidated Ontario Fire Code could not be retrieved during source work. Do not treat the historical amendment as complete current law.

## Skill behavior

Ontario requests should:

- preserve federal cannabis authority as a separate question from provincial safety, building, fire, pressure-equipment, environmental, municipal, and workplace obligations
- identify the actual site, municipality, building/facility scope, process hazard, and existing professional documents
- mark current-code questions as `REVERIFICATION_REQUIRED` when only historical or indexed evidence is available
- route engineering, fire, electrical, pressure, ventilation, and safety conclusions to qualified review

## Release limits

This overlay supports evidence routing only. It does not certify Ontario code compliance, authorize hazardous processing, approve construction or operation, or replace advice from the authority having jurisdiction.
