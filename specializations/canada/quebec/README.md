# Quebec cannabis overlay

Status: research overlay, not a site-specific compliance determination.

## Scope

This overlay records Quebec evidence routes for AgentCannabis skills involving workplace impairment, building/fire-code version questions, professional review, and French-language source handling.

## Current evidence

The source registry includes:

- `QC-CNESST-IMPAIRMENT`: CNESST workplace-impairment guidance in French.
- `QC-RBQ-CODE-2025-GUIDE`: RBQ explanatory guide for Quebec safety-code changes.

The Quebec LSST consolidation could not be retrieved during source work. The RBQ guide is explanatory; official regulatory text and transition provisions control.

## Skill behavior

Quebec requests should:

- preserve French source wording and flag translation uncertainty where relevant
- avoid copying Ontario or other provincial approvals into Quebec conclusions
- identify municipality, building history, transformation date, process scope, existing professional documents, and applicable authority questions
- route engineering, fire, building, employment, privacy, accommodation, and safety determinations to qualified human review

## Release limits

This overlay supports evidence routing only. It does not certify Quebec legal compliance, code compliance, employment decisions, or professional sign-off.
