# AgentCannabis Wiki

AgentCannabis is a public Agent Skills repository for Canadian cannabis compliance, quality, operations governance, and evidence-review workflows.

Current release: `v1.0.3`. Status: `V1_READY`.

## What is included

- 233 frozen atomic skills across 18 Master Taxonomy families
- 18 professional role skillsets
- 251 installable skill folders
- AgentSkills-style root routing templates under `agents/`
- GitHub Copilot install support through `gh skill install`
- Dated source registries and source-currentness rules
- Structural validation, review-gate tests, forward tests, integrated workflow tests, adversarial tests, and public install checks

## Operating principle

AgentCannabis helps agents prepare bounded evidence reviews. It does not authorize regulated cannabis activity, provide unsafe operational instructions, or replace responsible authorized humans and qualified professionals.
